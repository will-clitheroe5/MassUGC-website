MassUGC Website
===============

Files:
- index.html
- styles.css
- script.js

How to use:
1. Open index.html in a browser to preview the site.
2. Replace YOUR_CHECKOUT_LINK_HERE in index.html with your Stripe Payment Link, Gumroad URL, Lemon Squeezy checkout, or other hosted checkout URL.
3. Replace the three sample testimonials with verified customer quotes before publishing.
4. Replace hello@massugc.com if you use a different email.
5. Upload all three site files to any static host such as Netlify, Vercel, Cloudflare Pages, or your web host.

Recommended funnel setup:
- Checkout: Stripe Payment Link or Gumroad
- Delivery: Redirect customers after purchase to the PDF download, or automatically email the file through your checkout/email provider.
- Analytics: Add Meta Pixel, TikTok Pixel, and Google Analytics once you have those IDs.

Important:
The sample testimonials are intentionally labeled as samples on the live page so the site does not present fabricated customer endorsements as genuine.
